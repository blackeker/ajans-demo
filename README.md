## ✨ Temel Özellikler

- **🎨 Girişte 3D WebGL Sahnesi (Three.js)**:
  - Çoklu 3D geometri (*Torus Knot*, *Kristal*, *Kuantum*).
  - Fare takibi ve serbest 360° döndürme (drag-to-rotate).
  - Canlı HUD kontrol paneli (geometri, renkler, wireframe kafes modu, hız).
  - 60 FPS donanım hızlandırmalı render.

- **⚡ Entegre Sayfa Geçişleri (Page Transitions)**:
  - Menüden ve butonlardan geçişlerde çalışan akıcı shutter animasyonu.
  - Web Audio API ile sıfır harici dosya yüküyle çalışan ses efektleri (açılıp kapatılabilir).
  - Akıcı özel imleç (custom cursor).

- **💼 Sade & Odaklı Bölümler**:
  - **Hizmetler**: 3D WebGL, UI/UX & Tasarım, Yapay Zeka, Modern Web Mimarisi.
  - **Projeler**: Modern portfolyo kartları, filtreler ve detay önizleme modalı.
  - **İletişim**: Hızlı mesaj ve brief formu.

## 🚀 Hızlı Başlangıç (Local Kurulum)

```bash
# 1. Depoyu klonlayın
git clone https://github.com/blackeker/ajans-demo.git

# 2. Proje dizinine geçin
cd ajans-demo

# 3. Bağımlılıkları yükleyin
npm install

# 4. Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda `http://localhost:5173` adresini açarak deneyimleyebilirsiniz.
